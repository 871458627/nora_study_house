## 一、高(4 项)

**H1 服务端切年级「先删档、后 CAS」,并发冲突即条件性丢数据**
- 位置:`server/src/services/gradeService.ts:159`(删 toKey 存档)→ `:167-171`(casUpdate,未命中抛 409),全程无事务。
- 场景:双设备并发(docs/02 D12 明确支持)。设备 A 恢复存档后被设备 B 推送抢先 → A 的 CAS 409,此时目标年级存档已删、恢复内容未落库;家长重试 switch 走「全新开始」分支,进度静默清零。
- 依据:代码写序 + grade.test.ts 无并发用例;竞态窗口微秒级,外部无法确定性复现(如实标注)。两路子任务独立交叉确认。
- 修复方向:CAS 成功后再删档,或仓储层事务包裹。

**H2 「清空本机换账号」不清本机年级归档 → 跨家庭数据串号**
- 位置:`web/src/core/storage.ts` `clearLocalData`(只清 CACHE_KEY/PIN_KEY)vs `web/src/core/gradeArchive.ts:17`(归档为全局键、不分家庭);a5afc1c 的 wipe 分支未清理归档;`web/tests/accountSwitch.test.ts` 断言的键不含归档键,测试无法暴露。
- 场景:家庭 A 退出选「清空本机」后,其年级归档(含 lessons/错题/听写队列全量)残留;家庭 B 同机走未登录切换通道恢复同年级学期时,直接读出 A 孩子的进度——恰是 a5afc1c 自称要防的串号。
- 修复方向:wipe 一并移除归档键,或归档键按家庭维度隔离。

**H3 登录限速器过期条目永不清理,公开端点可无界吃内存(OOM)**
- 位置:`server/src/lib/attemptLimiter.ts:28-45`。key=IP|username,扫描器轮换用户名即产生一次性 key,只有写入无回收;自托管常驻单机 + Render 免费档 512MB 下,数日可被打满。
- 修复方向:命中过期条目顺手删除,或周期清扫(时钟已可注入)。

**H4 deploy/Dockerfile(node:20-alpine)× argon2 0.41.1:无 musl 预编译且镜像无编译工具链,自部署镜像构建大概率失败**
- 位置:`deploy/Dockerfile`(未装 python3/make/g++;`server/node_modules/argon2/prebuilds/` 实测仅 glibc 平台)。docs/09 自部署路径受影响;Render(runtime: node,glibc)不受影响。
- 置信:静态证据链完整(高置信),**未实测 `docker build`**。修复:apk 补工具链或换非 alpine 基础镜像,并实测。

## 二、中(12 项)

**M1 未登录横幅悬浮层遮挡页面底部控件(浏览器实测)**
- `LoginBanner` 为 `position:fixed; bottom:86px; z-index:90`,悬在底部导航上方,盖住流入该区域的内容。实测:PIN 设置页校验出错后,主按钮「设置并进入」被横幅覆盖,`elementFromPoint` 命中 banner 而非按钮——首次点击点在横幅上,用户感知「按钮没反应」;刷新后横幅重现。任何内容较长的页面都受影响。
- 修复:给页面内容预留 banner 高度的 padding,或横幅改为文档流内嵌。

**M2 无 `#` 深链被静默丢弃(实测 + 代码坐实)**
- `main.tsx:11` HashRouter 只读 hash;全库无 pathname→hash 恢复逻辑;两种既有部署(Render/nginx)均有 SPA fallback → 表现为静默回首页而非 404。外部分享/收藏/扫码链接全部失效;未来纯静态托管则升级为 404。
- 修复:入口处把非根 pathname 搬进 hash,或切 BrowserRouter(fallback 已具备)。

**M3 LearnGate 口径矛盾 + 死分支(实测 + 代码)**
- `canLearn = state.onboarded`(AppProvider.tsx:819):已初始化未登录设备永不弹门禁;门禁只拦访客/新设备,而解锁动作是「完成绑定+引导」——文案「家长登录后,才能开始学习」(LearnGate.tsx:21)误导;`:32/:35` 的「去登录/settings」分支不可达(旧口径死代码);OnboardingPage.tsx:23、AppProvider.tsx:816-817 注释同为旧口径。
- 实测补充:访客设备在练习/听写/运动页被拦,点「继续随便看看」跳回首页而非留在原页(LearnGate.tsx:37-38 硬编码 `navigate('/')`),且每次导航重现——访客实际上无法进行任何学习,与「学习照常」横幅直接矛盾。

**M4 server 未配置 trustProxy,反代部署下按 IP 限速全局聚合**
- `server/src/app.ts:135` 无 trustProxy;docs/07:301 明确要求。上线后 request.ip 恒为代理 IP → register 3/h、refresh 30/min、登录限速全部退化为全局共享配额,全站互相误锁。

**M5 grade 两条路由未挂限速,与路由注释自述矛盾**
- `server/src/routes/grade.ts:4` 注释称 30 次/分钟,实际 `:31/:53` 无 config.rateLimit(rate-limit 插件 global:false,未声明即不限速);实测响应无 x-ratelimit-* 头;违反 docs/03 §8.4-3。

**M6 双仓储 gradeArchives.upsert 的 createdAt 语义分叉**
- `server/src/repos/memory.ts:130-141`(每次覆写刷新 createdAt)vs `server/src/repos/prisma.ts:146-150`(保留首次);createdAt 直接外显并用于排序 → 测试(内存)与生产(Prisma)行为不同:测试过 ≠ 生产对。

**M7 RecordsPage 历史年级过滤条件写错**
- `web/src/pages/RecordsPage.tsx:114`:`(override ?? semester) === semester` 在未设学期覆盖时恒真 → 默认配置下当前年级两个学期的存档全部被隐藏(数据在,展示错)。应为 `override ?? autoSemester()`。

**M8 未登录通道 switchGrade 不 markDirty**
- `web/src/app/AppProvider.tsx:659-691` 本机切换不进推送队列:云端/他设备看不到年级变化;若云端 revision 被推进,`pullOnce` 回滚本机切换,而存档已被 `takeGradeArchive` 单副本消费,无法再恢复。

**M9 运动星星可「跌破达标线→再达标」反复刷**
- `web/src/core/sports.ts:98-102` + `state.ts:255-270`:同日同项目先达标(+1 星)→ 改小跌破 → 再改回达标 → 再 +1 星;每日 3 星上限只数「当前达标项数」未记「当日已发星数」,商城经济可绕过;sports 21 例测试未覆盖该场景。

**M10 本地快速开始端口断链:代理 8787 vs server 默认 3000**
- `web/vite.config.ts:10,16` 固定代理 8787;`server/src/config.ts:54` 默认 3000;README 快速开始无 `PORT=8787` 指引(本次排查启动后端时也必须手动设 PORT,佐证)。照 README 操作 → 前端正常、所有 /api 拒连。docs/07 又按 3000,两套口径并存。

**M11 docs/08 迁移步骤已失效**
- render.yaml 已于 8aacd2b 移除 xiaotao-migrate Job(Blueprint 规范无一次性 job 类型),docs/08 §二.3/§3/§四 仍教用户 Run Job,照做找不到;官方推荐 preDeployCommand 未采用。

**M12 测试覆盖缺口 + 「升版本即弃档」机制**
- 零测试:`web/src/core/pet.ts`、`web/src/app/handwritingEngine.ts`(securityEvents 已由新测试覆盖);server 侧 ratelimit 仅 1 例、repos/prisma.ts 无测试(设计内)。
- `core/model.ts:414-415` schemaVersion 严格相等校验:不匹配即整个存档判 null——当前 v1 无实害,但未来任何升版本会静默清空所有本地/云端存档,且无迁移机制与测试防护。

## 三、低(按主题归组)

**交互与体验**
1. 引导第 4 步设置的 PIN 在绑定云端后被丢弃,随即再次要求设置(实测:step-4 设 1234 → 完成绑定 → 「这台设备还没有家长 PIN」重问)。疑似与绑定/a5afc1c wipe 重置设备态相关,需确认是否设计意图;若非,应保留已设 PIN。
2. 运动页同值更新无反馈、同名自定义项假成功(SportsPage.tsx:94,108-120);底部/桌面导航无运动入口,发现性依赖两处深链;focusRoute 沉浸正则漏 /sports。
3. 切年级无静默续期:token 失效时报「请先登录」与已登录状态矛盾(AppProvider.tsx:700 未经 runWithAuthRetry)。
4. 连续打卡 streak 跨天不重置,显示过期值直到下次打卡。

**正确性隐患(现无实害)**
5. 归档「非空判定」口径不一:本机 `sliceIsNonEmpty`(gradeArchive.ts:104-113)漏 dictationQueue,纯听写进度切年级会丢,登录通道则不丢。
6. 年级下拉联动把手动换册意图静默重置为自动学期(SettingsPage.tsx:150-160,新增路径,旧版同年级直接 return)。
7. reducer 非纯(内联 Date.now/new Date)+ `dispatchLocal` 双重归约 → stateRef 与 React state 在时间戳/id 上漂移(AppProvider.tsx:485-490)。
8. `normalizeSports` 接受 0 值日志(model.ts:383)而 reducer 禁止写 0:外部注入数据可把 0 值计为「已打卡」并推 +1 桃粮;`sports-custom-add` 不查内置重名,撞 id 会连带清内置项历史。
9. 无顶层 ErrorBoundary(main.tsx 裸渲染):任何渲染异常=整树白屏;当前未发现具体触发向量,建议补。
10. wipe 退出无错误反馈(handleLogout 无 catch)+ 在途推送竞态可写回旧家庭 revision;wipe 未清 pinUnlock 的 sessionStorage 键(需家长权限才可触发,风险低)。

**规范/文档/配置**
11. `gradeService.ts:51-57` archiveSummary 恒假表达式(`isRecord(m) && !isRecord(m)`),行为凑巧正确、表达式误导。
12. docs 数字/命令过时:README「63 个单测」(实测 141+72)、docs/04 全篇(引用不存在的 `test:server`/STATUS.md/ARCHITECTURE.md、supertest)、「六表」实为 7 模型、docs/08 lock 排障建议与单根 lock 现实不符。
13. `deploy/backup.sh`/`restore.sh` 不加载 .env,自定义库名/用户名时备份指向错误库。
14. XTAO_REPO 三处设置、零消费(死配置);render.yaml 迁移未用官方推荐 preDeployCommand。
15. `.dockerignore` 缺 `gui-test-screenshots/`、`.zwork/`、`deploy/.env`(构建上下文外发面);`.zwork/` 靠嵌套 ignore 未显式列入根 .gitignore。
16. engines/版本漂移:仅 server 声明 node>=20,@types/node^24 vs 运行时 20 / 镜像 20-alpine。
17. PIN 为单轮 SHA-256(salt:pin),4 位空间可离线穷举(本机门锁定位下可接受,可 PBKDF2 加固);crypto.subtle 仅 https/localhost 可用,自建 http 部署 PIN 必失败(现有部署不触发);本地 http 下 refresh cookie 带 Secure,Safari 拒收(联调注意)。
18. LessonPage 不校验路由 :subject(`/textbook/math/en-u1-l1` 也渲染英语课,宽容不致错;做深链规范化时留意)。
