## 1. 现有视觉语言盘点

global.css 开头自述设计基调：「近白纸面、单一玫红、发丝分隔、大标题、克制的动效」。以下为实际提取值。

### 1.1 色彩 token（:root）

**基础面与文字**

| Token | 值 | 用途 |
|---|---|---|
| `--bg` | `#fbfbfd` | 页面底色（近白） |
| `--surface` | `#ffffff` | 卡片面 |
| `--ink` | `#1d1d1f` | 主文字（白底对比约 16.7:1） |
| `--sub` | `#6e6e73` | 次级文字（白底约 5.1:1） |
| `--ter` | `#86868b` | 三级辅助文字（白底约 3.6:1，仅限非关键信息，见 §5） |
| `--line` | `#e5e5ea` | 发丝分隔线 / 卡片描边 |
| `--line-soft` | `#efeff2` | 更浅的列表内分隔 |

**品牌与语义色（每个语义色都有 soft 底色配对）**

| Token | 值 | soft 底 | 语义 |
|---|---|---|---|
| `--accent` | `#c1355e` | `--rose-soft: #fbeaf0` | 品牌玫红：主按钮、选中态、进行中 |
| `--accent-deep` | `#a02a4c` | — | 玫红深阶：hover、soft 底上的文字 |
| `--rose` | `#e4698f` | — | 玫红浅阶：图标点缀、浅强调 |
| `--mint` | `#2e7d62` | `--mint-soft: #e8f4ef` | 成功 / 已完成（对题、任务 done、已同步） |
| `--amber` | `#8a6a1f` | `--amber-soft: #fff6df` | 温和提示 / 已回顾 / 徽章 / 打卡 streak |
| `--danger` | `#b3261e` | `--danger-soft: #fdeceb` | 错误（**永远 soft 底 + 深字**，不大面积纯红） |

氛围底色：`body::before` 顶部 420px 玫瑰径向渐变（`rgba(251,234,240,0.7)` 渐隐）；引导页叠 mint 径向；今天 hero、宠物卡使用 `linear-gradient(115deg~140deg, #fff 34%~45%, #fff3f7)` 级的白→粉微渐变。

**三科主题色**（数据层定义于 `src/data/content/index.ts`，由 `SubjectChip` 以行内 CSS 变量 `--subject-color` / `--subject-soft` 注入，global.css 不含硬编码）：

| 科目 | color | soft | 与全局 token 的关系 |
|---|---|---|---|
| 语文 | `#C1355E` | `#FBEBEF` | 与 `--accent` 同值，品牌色即语文色 |
| 数学 | `#2F6F62` | `#EAF5F1` | 与 `--mint`(#2e7d62) **相近但不同值** |
| 英语 | `#8A5A21` | `#FBF1E2` | 与 `--amber`(#8a6a1f) **相近但不同值** |

> 注意：`--mint`/`--amber` 是语义色（成功/提示），数学/英语色是科目标识色。新界面中"语义"一律走全局 token，"科目归属"才注入 `--subject-*`，不得混用。

**状态胶囊色**（.status-pill 变体，可作新状态设计的先例）：current 玫红系、previewed `#eef3fb`/`#3a6ba5`（蓝，唯一冷色）、reviewed 琥珀系、mastered 薄荷系；热力格 `#f1f1f4 → #f9dbe5 → #eda2ba → --accent` 四档。

### 1.3 间距与布局

- 页面骨架：`.page-wrap` max-width **1120px**，padding `36px 24px 96px`（≤920px 为 `26px 20px 104px`，≤720px 为 `22px 16px 104px`，底部让位给底栏）。
- 双栏栅格：主栏 + 右栏（318px / 308px / 300px），≤920px 折单栏；答题专注模式 `.focus-mode` 取消 padding、`.session-shell` max-width **760px**。
- 常用 gap 阶梯：`2/3 → 5–8 → 9–14（列表行）→ 16–18（卡内分节）→ 20–28（页面分节）`。
- 卡片 padding：rail 卡 16–18、settings-card 22、quiz-card 26、summary 28–34、modal 26、pin-gate 28–30。
- 触控安全：行间距 ≥8px（.option-list gap 9、.keypad gap 8 为下限先例）。

### 1.4 圆角阶梯

`999px`（按钮/胶囊）→ `24px`（.modal）→ `22px`（`--radius`，卡片）→ `14px`（`--radius-sm`；option、order、输入框 12–14）→ `16–18px`（task-row、wardrobe-item、unit-card）→ `8–11px`（小 chip、match-item）→ `3.5px`（heat-cell）。新增元素从该阶梯取值，不发明中间值。

### 1.5 阴影与 z-index

- `--shadow: 0 1px 2px rgba(29,29,31,.04), 0 14px 34px rgba(29,29,31,.045)`（卡片）
- `--shadow-lift: 0 2px 4px …, 0 18px 42px …`（悬停抬升）
- 主按钮专用彩色投影 `0 6px 16px rgba(193,53,94,.18)`；小喇叭大按钮 `0 12px 30px rgba(193,53,94,.28)`；modal `0 30px 80px rgba(29,29,31,.22)`。quiet 卡（`#f8f8fa`）去阴影。
- z-index 阶梯：nav 50 / mobile-nav 60 / pending-conflict 90 / modal 100 / toast 120。

### 1.6 动效时长与缓动（详见 §4）

微交互 0.10–0.18s；状态切换 0.2–0.24s；进度类 0.32–0.45s；签名缓动 `cubic-bezier(0.22, 0.68, 0.35, 1)`（progress/modal/toast 三处复用）。已有 `@media (prefers-reduced-motion: reduce)` 全局降级。

### 1.7 断点

`1080px`（右栏收窄）→ `920px`（桌面导航隐藏、底部 5 标签栏出现、双栏→单栏）→ `720px`（紧凑 padding、卡片内折行）→ `430px`（hero 纵排、任务行紧凑）。底部栏含 `env(safe-area-inset-bottom)`。

### 1.8 图标风格（Icon.tsx）

- 33 个命名图标；统一 **24×24 viewBox、`stroke="currentColor"`、`stroke-width` 1.8（可调）、`stroke-linecap/linejoin: round`、`fill: none`**（仅瞳孔/徽章星等极小点用 currentColor 实心）。
- 尺寸使用区间 11–52px，颜色 100% 继承文字色，无自带配色。
- 新增图标（本规范的 `qr`、`shield`）必须延续该规格：纯线条、圆角端点、单色、无渐变。

### 1.9 Mascot 风格（Mascot.tsx）

- viewBox **120×130**（宽高比固定），`size` 属性控制渲染尺寸，带 `role="img"` + 中文 `aria-label`（如「小桃在为你庆祝」）。
- mood 五档：`happy / normal / hungry / sad / celebrate`（celebrate 为隐藏庆祝档，自带两枚四角星）。
- 手绘色板：身体 `#F9D9E2`（sad 变灰粉 `#F6D2DC`）、耳 `#F6BCCB`/内耳 `#FDE3EA`、描边 `#E7A5B8` 2.2px、腮红 `#EFA3B8` 50%、头顶嫩叶 `#9FD3BE`、五官线 `#7C5362`、眼泪 `#9CCDE8`、庆祝星 `#E4698F` / `#FFE8A3`。
- 配饰槽位 `head`（bow 蝴蝶结 / crown 皇冠）、`neck`（scarf 围巾 / cape 披风）、`face`（glasses 眼镜），配饰自带描边深色（如 crown `#FFE8A3`+`#D8B35A`）。
- **定位**：Mascot 是情绪出口——庆祝、安慰、空状态优先用它替文字说话（TodayPage 空计划、PetPage 舞台均如此）。

### 1.11 命名约定（新 class 必须遵守）

global.css 的「BEM-ish」实为**扁平短横线**：根类 `.block-element` 一路连写（`.task-row`、`.pet-stage-caption`），**不用 `__` / `--` 符号**；状态或变体作为并列的独立 class（`.done`、`.locked`、`.equipped`、`.active`、`.quiet`、`.warn`、`.compact`、`.full`）。CSS 变量为 `--kebab-case`；组件级主题变量用 `--subject-color` / `--subject-soft` 注入模式。本规范新增类名全部遵循此约定。

### 1.12 「必须延续」清单（新界面验收红线）

1. 近白纸面：`--bg` + 顶部玫瑰氛围渐变；大面积深色只允许 `.toast` 与 `.modal-backdrop`。
2. 单一玫红主操作：每屏 **最多一个** `.btn-primary`；次级用 `.btn-soft`，三级用 `.btn-ghost`。
3. 卡片三件套：白面 + 1px `--line` + `--radius`(22) + `--shadow`；弱信息用 quiet 卡去阴影。
4. 文字三级 `--ink/--sub/--ter`，`--ter` 不承载关键信息（对比度仅 3.6:1）。
5. 语义色成对使用：soft 底 + 深字；错误反馈永远是 `--danger-soft` 底，禁止大面积纯红。
6. 交互元素触控热区 ≥44px（先例：.text-link、.switch、.seg、.btn）。
7. 图标只用 Icon.tsx 体系（24 viewBox / stroke 1.8 / currentColor），不引第三方图标。
8. Mascot 承担情绪表达；庆祝/安慰不用长文字。
9. 动效 0.10–0.45s、签名缓动；无限循环仅限状态指示（pulse-dot / bob），奖励动效一次性播放。
10. 断点 1080/920/720/430；≤920 出现底部 5 标签栏 + safe-area；答题专注模式沿用 `.focus-mode` 隐藏导航。
11. 焦点可见：`:focus-visible` 2px `--accent` 外框 + 2px 偏移；图标按钮配 `.sr-only` 或 aria-label。
12. 新类名遵循 §1.11 扁平短横线约定；科目色走 `--subject-*` 注入，语义色走全局 token。
13. **圆角安全（2026-10-27 用户裁定红线）**：`.card` 是**无内边距的裸容器**（仅背景 + 边框 + 圆角 + 阴影，`global.css` §.card）——凡是圆角容器，内容必须由使用它的页面类自带 padding（卡片统一 **14–18px**）；文字、图标、分隔线**不得与圆角弧线相交、不得溢出容器任何一边**（尤其底部）。出现「文字压在圆角边框前/后」即验收直接打回的缺陷，修复方式是给容器类补 padding，而不是挪文字。
14. **全站风格统一（2026-10-27 用户裁定红线）**：所有页面只允许使用 §1.1 的全局 token 与本清单组件规范，禁止页面私配色值、私有圆角、私有阴影；同一语义全站只用一种视觉表达（达标态=绿、主操作=主色 token、禁用=soft 灰）。新增页面上线前按本清单逐条自查；每页至少抽查一张圆角卡片的四边。

## 2. 儿童向设计原则

### 2.1 触控目标 ≥44px

- 现有先例：`.text-link` 以「padding 撑到 44×44 + 负 margin 拉回视觉盒」实现小视觉大热区（css 内有英文注释明确此意图）；`.switch` 隐形 input 外扩 `inset: -8px -6px`；`.btn`/`.seg`/`.session-back` 均 min-height 44；`.option-btn` 54、`.key-btn` 50、`.dictation-option` 60、`.mobile-tab` 52。
- **规则**：儿童可点的目标一律 ≥44×44，相邻目标净距 ≥8px；视觉可以小于 44（用 padding + 负 margin 技法），热区不行。现有 `.icon-btn` 38px 属成人向例外，**新增儿童向图标按钮不得复用 38px**，按 §3.5 规格做 44px。
- 破坏性 / 越权操作（改 PIN、重置、退出登录）必须落在 modal 或 PIN 门后，不放在拇指热区常驻位置。

### 2.2 信息层级

- 沿用「eyebrow → H1 → lede → hero 卡（大数字）→ 卡片列表」的既有节奏；每屏一个视觉锚点（大数字或 Mascot）。
- 每屏一个主按钮；数字用 `.big-number` 一级的展示字重，让"完成了多少"一眼可读，不依赖阅读。

### 2.3 正反馈用色

- 对：`--mint` 图标 + `--mint-soft` 底 + 勾形图标（option-mark 先例），三重编码（色 + 图标 + 文案）。
- 错：`--danger-soft` 底 + `#f0c9c4` 描边 + danger 图标圆点，**不用纯红填充**、不闪烁、不抖动（shake 类动效禁用——避免挫败放大）。
- 奖励/成就：amber 家族（徽章 earned、streak 先例）+ Mascot celebrate；星星经济统一 amber（见 §3.3）。
- 批评性文案口吻沿用现有「不没收已得到的奖励」式温和措辞。

### 2.4 文字量控制（二年级识字量）

- 儿童操作面：按钮动词 ≤4 字（「喂桃粮」「再做一遍」「兑换」）；说明句 ≤2 个分句、每句 ≤18 字；生僻概念配图标或拼音（听写页已有 `.pinyin-prompt` 先例）。
- 关键数字永远阿拉伯数字 + 大字重；说明性长句只出现在家长区（隐私页、周报、设置），家长区可放宽到 12.5–14.5px 正文。
- 儿童面正文字号下限 13.5px（task-copy b 先例），辅文下限 11.5px；**禁止出现新的 <9.5px 文字**（现有 7.5–9px 仅历史遗留的极小注）。
- 标签截断（ellipsis）只用于标题行，不用于操作说明。

## 4. 动效规范

### 4.1 时长与缓动（值全部取自 global.css 现有用例）

| 场景 | 时长 | 缓动 | 先例 |
|---|---|---|---|
| 按压反馈（scale .985/.96） | 0.10–0.12s | ease | .key-btn / .btn:active |
| hover 变色 / 描边 | 0.14–0.18s | ease | .match-item / .nav-links / .btn |
| 开关、分段、折叠箭头 | 0.16–0.22s | ease | .switch / .unit-chevron |
| 弹层入场（modal / toast） | 0.18–0.24s | `cubic-bezier(0.22, 0.68, 0.35, 1)` | fade-in / modal-in / toast-in |
| 进度条宽度 | 0.32 / 0.45s | 0.45s 用签名缓动 | .session-progress / .progress |
| 兑换星星飞行（新） | 0.45s | `cubic-bezier(0.22, 0.68, 0.35, 1)` | 对齐 .progress |
| 状态指示循环 | 1.1s / 2.6s | ease-in-out infinite | pulse-dot / bob（**仅此用途允许循环**） |

**规则**：新动效一律从上表取值；缓动只用 `ease` 与签名贝塞尔两种，不新增曲线。签名缓动在 css 中已硬编码出现 3 次，建议提炼为 token `--ease-soft: cubic-bezier(0.22, 0.68, 0.35, 1)`（见 §6）。

### 4.2 克制的奖励动效原则（防过度刺激）

1. 奖励动效 = **一次性、短促、可预期**：兑换飞星 0.45s、庆祝粒子 ≤0.8s，播完即清 DOM。
2. 循环动画只表达"进行中"状态（同步中呼吸点、朗读中呼吸环），奖励永不循环。
3. 同屏至多一种奖励动效；动效不阻塞交互（纯装饰层 `pointer-events: none`）。
4. 不用全屏闪光、大幅位移、抖动；错误态零动效（只有静态 soft 底色 + 图标）。
5. 数值反馈优先"小而准"：余额数字 0.24s 补间 > 弹跳 +N 大字。

### 4.3 prefers-reduced-motion 兼容

global.css 已有全局降级（animation/transition 全部 0.01ms、scroll-behavior auto）。新动效只需：

- 不使用 JS 强制动画（WAAPI/SVG SMIL 也要先读 `matchMedia('(prefers-reduced-motion: reduce)')`）；
- 飞星/庆祝粒子在降级模式下直接跳到终态（余额数字立即更新、Mascot 静态 celebrate）；
- 呼吸环降级为静态实心描边（状态仍靠颜色 + 文字标识，不失效）。

## 5. 无障碍要点

### 5.1 对比度（白底近似值，按 WCAG 对比公式计算）

| 组合 | 对比度 | 判定与规则 |
|---|---|---|
| `--ink` / 白 | ≈16.7:1 | AAA |
| `--sub` / 白 | ≈5.1:1 | AA，辅文基准 |
| `--ter` / 白 | ≈3.6:1 | **未达 AA 正文（4.5）**：仅限 ≥18.5px 大字或装饰性微标签；关键信息一律 `--sub` 起步（现状 9–11px 大量用 ter，新界面关键辅文改用 `--sub`） |
| `--accent` / 白 | ≈5.3:1 | AA，链接与主按钮（白字于 accent 同 ≈5.3:1） |
| `--accent` / `--rose-soft` | ≈4.6:1 | 临界——**rose-soft 底上文字用 `--accent-deep`**（≈6.2:1，.btn-soft 已是正确先例） |
| `--amber` / `--amber-soft` | ≈4.7:1 | 临界通过；星星文案字重 ≥600 保证可读 |
| `--mint` / `--mint-soft` | ≈4.4:1 | **略低于 4.5**：现有 .feedback-card.correct b 即此组合，属遗留问题；新界面在 mint-soft 上写正文请用 `#2F6F62`（数学主色，≈5.2:1）或加深 mint |
| `--danger` / `--danger-soft` | ≈5.7:1 | AA，错误反馈安全 |

### 5.2 不单靠颜色区分

- 连线题：`.match-item` 配对后除 rose-soft 底色外，必须保留 `small` 中的配对字母/序号（现状已有，须延续）；新界面所有"选中/完成/锁定"态一律 **色 + 图标/文字 + 形状（描边或底色）** 三重编码。
- 先例清单可直接引用：option-mark 对勾圆标、task-action.done 勾、wardrobe-lock 锁形、week-day.rest 的「休」字 + leaf 图标、读题小喇叭三态各配文字标签。
- 焦点可见性即无障碍冗余：保留 `:focus-visible` 2px accent 外框，不用 outline:none 覆盖。

### 5.3 字号缩放行为

- 现体系全 px + 展示层 `clamp()`：系统字号放大时 px 不随 rem 缩放，因此**信息不得只放小于 11.5px 的层级**；`.quiz-stem` 的 clamp 保证题干随视口放大。
- 布局必须容忍文字放大 125%：行内 flex 允许换行（.settings-row ≤720 变纵向的先例）；按钮高度 44 为下限不是上限（`min-height` 而非 height）。
- 标题截断（ellipsis）仅限列表标题；题目、说明、按钮文字永不截断。

### 5.4 语义与读屏

- 图标按钮必带 `aria-label`（Icon 本体 `aria-hidden`）；Mascot 的 mood `aria-label` 惯例延续到新场景。
- Toast `role="status"`、进度条 `role="progressbar"`、小喇叭 speaking 态 `aria-live="polite"` 均为既有/本规范约定。
- 阅读顺序：读题按钮在 DOM 中位于题干之前（视觉与 DOM 一致），保证读屏先听到"读题"再听到题目。
