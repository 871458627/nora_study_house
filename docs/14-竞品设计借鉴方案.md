# 14 · 竞品设计借鉴方案（2026-10-31）

- **角色**：产品经理 + 交互设计
- **前置**：`docs/13-竞品分析.md`（市场格局）。本文只做一件事——**提取竞品中真正优秀的设计方案，逐个评估能否融入小桃学习屋**，能的给落地方案，不能的写明为什么排除。
- **评估三把尺**（每个设计都过一遍，任何一把不过就不做）：
  1. **哲学契合**：不与"答错不惩罚、无广告无订阅、数据自主、减少屏幕时间"冲突；
  2. **架构可行**：能在现有机制上落（内容包 / 错题快照 / PWA / 朗读器 / 年级归档），不引入商业化依赖；
  3. **成本收益**：单家庭场景收益明确，工作量与收益匹配。

---

## 一、融入清单（按性价比排序）

### 1. 错题练习卷导出打印 ⭐ 本轮最推荐

- **来源**：小猿口算"一键打印错题本"（错题自动归集后一键导出 PDF，2021-2023 年上线，实测真实存在）。
- **为什么优秀**：把**数字错题送回纸质练习**——孩子离开屏幕做题（契合减屏时间理念），纸笔书写正是二上语文田字格、数学竖式的课标要求；家长不用手抄错题（真实痛点，抄错题是家长最烦的家务之一）。
- **小桃适配**：✅ 完全契合。错题数据已就绪（课本题按课归属、口算快照题自带题目），前端生成即可，**零新依赖、零服务器改动**。
- **融入方案**：记录页错题本加「导出练习卷」按钮 → 生成打印友好页面（新窗口/独立路由 `#/mistake-print`）：
  - 布局：A4 纵向，标题（日期区间 + "数学错题练习卷"）+ 题目列（每题留答题空间）+ 页脚答案页（与题目分页，家长对答案）；
  - 语文听写错词同时导出（田字格空格行）；
  - `@media print` 样式隐藏导航，浏览器自带的"打印→存 PDF"即完成，不需要 PDF 库；
  - 数据流：纯前端从 `state.mistakes` 生成，离线可用。
- **工作量**：1 天（含打印样式调试）。**优先级：P1 下一批次首位**。

### 2. 错题"讲解卡"（重做页增强）

- **来源**：小猿AI 错题五维错因分析 + 讯飞"错题 100% 讲解"。
- **为什么优秀**：错题的价值在"为什么错"，竞品把讲解做成重做闭环的一部分（先看讲解 → 再做变式）。小桃重做页现在只有做错后的 `explanation` 一句话，重做前没有引导。
- **小桃适配**：✅ 架构现成——`Question.explanation` 已存在于数据结构；朗读器可以把讲解读出来（无需视频制作，文字平替讯飞的视频讲解）。
- **融入方案**：重做页（MistakeRetryPage）在答题前展示**可折叠的"想一想"提示卡**（默认折叠防剧透：先给方向性提示，如"先想进位"、"想想 7 的口诀"；展开显示完整 explanation）；口算快照题配生成时的口诀说明。
- **工作量**：半天。**优先级：P1**。

### 3. 连续打卡桌面小组件（Streak Widget）

- **来源**：Duolingo 的 streak widget（把连续天数钉在手机首屏，App 未开也在提醒"别忘了今天"）。
- **为什么优秀**：习惯类产品的核心指标放在系统级可视位置，打开成本趋近于零；对家长是"今天学了没"的一眼确认。
- **小桃适配**：✅ PWA 基础已具备（manifest + service worker），Chrome/Edge 支持 `widgets` 字段（Android）；iOS 走"添加到主屏幕"的替代方案是 PWA 图标角标（不可行）→ 退化为主屏快捷方式 + 通知（暂缓）。
- **融入方案**：`manifest.webmanifest` 增加 `widgets` 声明（Android Chrome 9+ 支持），展示"连续 N 天 · 今日 X/Y 项"（数据从 SW 拿不到 state——用 `navigator.serviceWorker` postMessage 或 IndexDB 同步今日摘要；最小版只展示 streak，用 localStorage 在每次状态变更时写入）。
- **工作量**：1 天（Android 生效，iOS 无小组件能力如实标注）。**优先级：P2**。

### 4. 成长收藏册扩展

- **来源**：Khan Academy Kids 的可收集角色（完成活动解锁新伙伴，收集驱动重复使用）。
- **为什么优秀**：把"进步"物化为可收藏、可回看的实体，比纯数字积分更有情感沉淀；孩子会为"集齐"而主动学习。
- **小桃适配**：✅ 相册（album）机制已存在（进化里程碑），徽章/衣柜已就绪——只差把"每掌握 N 课、每个徽章、每次阶段进化"生成一页收藏插画挂进相册。
- **融入方案**：相册页按时间线展示里程碑插画（美术资源复用 Mascot 五表情 + 配饰组合，无需新美术）；每页配一句成长寄语（朗读器可读出寄语）。
- **工作量**：1 天。**优先级：P2**。

### 5. 每日目标报告（一句话式）

- **来源**：洪恩识字的家长面板（每日目标、识字报告）。
- **为什么优秀**：家长不开周报也能 30 秒掌握当天情况——周报是周维度，缺一个"今天"维度。
- **小桃适配**：✅ 今天页顶部进度环已承担孩子侧；家长侧差一个**摘要句**。
- **融入方案**：设置页或周报顶部加"今日一句话"：`果果今天完成 2/3 项，用时 11 分钟，听写全对。`（数据全在 dailyLog）。与 #10 实际用时打通后价值更大。
- **工作量**：2 小时。**优先级：P2**。

## 二、明确排除清单（写下来防止将来误加）

| 竞品设计 | 来源 | 排除理由 |
|---|---|---|
| Hearts/生命值（答错扣心、心尽不能学） | Duolingo | 与"答错不惩罚、不没收奖励"哲学正面冲突；对低龄儿童制造挫败 |
| 排行榜/联赛（陌生人对比） | Duolingo | 单家庭自托管无社交基础；儿童产品引入同龄对比制造焦虑 |
| 老师建班/班级作业同步 | 一起作业 | 与"家庭自主"定位冲突，且该模式的差评（负担投诉）是前车之鉴 |
| AI 精准学·步骤级诊断 | 讯飞学习机 | 需要海量跨用户数据训练，单家庭数据量不足，硬做是伪精准 |
| 订阅墙/广告/硬件绑定 | 行业通例 | 商业模式红线，永不加入 |

## 三、实施建议

1. **P1 下一批次**：错题练习卷导出打印（#1）+ 讲解卡（#2）——两者都在错题闭环上，一起做收益最大（做完后错题本从"记录"升级为"训练场"）；
2. **P2**：小组件（#3）+ 收藏册（#4）+ 每日一句话（#5）；
3. **观察项**（不排期）：拍照批改口算纸、AI 答疑——待教材导入的 AI 通道（docs/11）落地后自然解锁，届时拍照批改与"自备教材生成练习"共用同一视觉识别能力。

**不建议现在做的**：把竞品的功能清单直接抄成路线图（如学习机的 9 大功能）。小桃的竞争力在"少而准 + 数据自主"，功能膨胀反而稀释定位。
