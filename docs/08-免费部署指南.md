# 08 · 免费部署指南（Render + Neon）

- **角色**：部署运维（方案评估与落地适配由本团队完成，2026-10-25）
- **结论**：选定 **Render 免费 Web Service（跑 API + 同源托管前端）+ Neon 免费 PostgreSQL**。这是同时满足本项目两个硬约束的唯一真免费组合：
  1. **必须同源**——refresh cookie 为 `SameSite=Strict; Path=/api/v1/auth`，前后端分域会导致 cookie 拒发、登录态失效。已由 Fastify 直接托管 `web/dist` 解决（`WEB_DIST_DIR`）。
  2. **必须常驻进程**——登录限速器与 @fastify/rate-limit 状态在进程内存。因此 Vercel/Netlify serverless 不可用。
- **备选**：Oracle Cloud 永久免费 ARM VM 按 `docs/07` 的 Docker 方案一台机全跑（不休眠，但注册要信用卡、容量看运气）；`docs/07` 完整生产方案（备份/监控/回滚）继续有效。

## 一、额度核对（单家庭用量 << 免费额度）

| 资源 | 免费额度 | 本项目预估 |
|---|---|---|
| Render 实例 | 750 实例小时/月，512MB RAM | 744 小时/月（单服务全天），刚好覆盖 |
| Render 休眠 | 15 分钟无流量休眠，冷启动 30–60s | 家庭早晚各同步一次，影响极小；介意可用 cron-job.org 每 10 分钟 ping `/api/v1/health` 保活 |
| Neon 存储 | 0.5GB | 全量数据 <10MB |
| Neon 计算 | 100 CU·时/月，闲置 5 分钟自动挂起（唤醒 <1s） | 每天几十次请求，用量 <1% |
| 带宽 | Render 约 5GB/月 | 前端包 <1MB，远够 |

注意：**不要用 Render 自带免费 Postgres（30 天删除）**，数据库一律放 Neon。

## 二、部署步骤（约 15 分钟）

### 1. 建 Neon 数据库（5 分钟）

1. 注册 <https://neon.tech>（GitHub 账号即可）→ Create Project，区域选 `Singapore`（离国内最近）。
2. Dashboard → **Connection string** 复制，形如 `postgresql://user:pass@ep-xxx.aws-singapore-1.aws.neon.tech/neondb?sslmode=require`。

### 2. Render 部署（10 分钟）

1. 代码推到 GitHub / GitLab（本仓库）。
2. Render 控制台 → **New → Blueprint** → 选中仓库（识别根目录 `render.yaml`）。
3. 会提示输入两个 `DATABASE_URL`（web 与 migrate 两个服务各一个）——粘贴 Neon 连接串。
4. Apply。Render 自动执行：`web` 构建（前端 + 后端 + prisma generate）并启动；`xiaotao-migrate` Job 先 **手动 Run一次**（`prisma migrate deploy` 建六张表）。
5. 打开 `https://xiaotao-app.onrender.com/api/v1/health` 应返回 `{"ok":true,...}`；打开根路径应看到前端页面。**同源验证**：浏览器 DevTools 里 refresh cookie 的 `Secure; SameSite=Strict; Path=/api/v1/auth` 三件套齐全。

### 3. 首次使用

家长设备打开站点 → 注册账号（用户名 3-32 位字母数字、密码 ≥8 位）→ 引导流程；孩子设备用同一账号登录即绑定同一家庭。

## 三、环境变量清单（render.yaml 已固化，仅需人工填 DATABASE_URL）

| 变量 | 值 | 说明 |
|---|---|---|
| `DATABASE_URL` | Neon 连接串（**sync:false，控制台输入**） | 两个服务都要填 |
| `JWT_SECRET` | Render `generateValue: true` 自动生成 ≥32 字节 | 轮换会使所有 access/refresh 失效，需提前通知 |
| `XTAO_REPO` | `prisma` | 内存仓储仅限本地 |
| `WEB_DIST_DIR` | `../web/dist` | 相对 server 启动目录 |
| `HOST` | `0.0.0.0` | 容器内必须 |

## 四、运维要点（免费档特有）

- **冷启动**：休眠后首次请求慢 30–60 秒。PWA + localStorage 缓存使离线体验不受影响；保活见上表。
- **迁移**：schema 变更 → 新增 migration 目录 → 推送后在 Render 控制台 Run `xiaotao-migrate` Job。
- **备份**：云端 `family_state_history` 环形 5 版 + 每周日家长应用内导出 JSON（docs/07 双路恢复不变）。
- **额度耗尽表现**：750 小时用尽（几乎不可能，单服务 744h）→ 服务停到月底；Neon 超存储 → 拒绝写入，注意归档机制（P0 状态归档）控制体积。
- **密钥红线**：Neon 连接串与 JWT_SECRET 只存 Render 环境变量，绝不入仓库；`.env` 已被 .gitignore 排除。
